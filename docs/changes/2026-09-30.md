# 2026-09-30 修改日志

**日期**：2026-09-30
**完成/验收**：2026-10-01
**修改原因**：旧 YoboGo-10S Webots 模型把 `0.14 + 0.12 = 0.26 m` 的腿段长度直接当作站立高度，模型零位呈大腿与小腿共线的直腿姿态；同时未配置显式机械限位，足端视觉球不参与碰撞，导致步态视频中腿姿僵直、比例不自然。依据同款机器人的《四足仿生机器人基本原理及开发教程》课件，重构模型几何、零位、限位、足端接触和四连杆外观。

**当前状态**：模型生成器、三个源 world、静态一致性检查和 Webots 批处理加载验证均已完成；参数符合本轮 `0.15/0.15 m`、约 `120°` 屈膝和工程暂定限位目标。腿段、四连杆、真实机械限位及数值零位仍待 CAD/实机标定；旧控制器与旧 checkpoint 未作为验收依据。

## 3. 本轮模型重构约定

1. 保持每腿 `abd / hip / kn` 三个驱动关节，总计 12 个 `HingeJoint`、12 个 `RotationalMotor`、12 个 `PositionSensor`。
2. 默认工程腿段采用 `thigh = shank = 0.15 m`，自然屈膝约 `120°`，使约 `0.26 m` 站立高度来自折线腿而非共线腿。
3. 暂定安全限位：`abd = ±0.6 rad`、`hip = ±1.0 rad`、`kn = ±1.0 rad`；所有关节同时写 `minPosition/maxPosition` 与 `minStop/maxStop`。这些值是**工程标定暂定值**，不是实机机械限位。
4. 足端球或弧面必须进入 `boundingObject`；已增加 4 个 `*_foot_touch` `TouchSensor`，但不接入现有 RL 观测。
5. 四连杆/平行四边形只作为跟随三个驱动关节的外观件，不新增闭链或被动关节。
6. 模型关节零位、实机编码器零位、自然站立角必须分别记录，不得互相冒充。
7. 参数来源必须区分课件原文、说明书原文、现有代码、图片比例测量、工程估算、工程暂定和待实机/CAD确认。
