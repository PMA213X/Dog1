# 2026-10-05 变更记录

## 官方 Mini Cheetah R3 P0 故障修复

- 日期：2026-10-05
- 原因：R3 P0 的三批失败同时受接触 API、冷启动 RSI、评估随机化和
  Gate 语义错位影响，不能继续把污染 checkpoint 当作有效训练起点。
- 状态：代码、测试与文档同步完成；`80/80` 单测、四机 train dry-run、
  `rl.run_stages --dry-run`、P0 evaluate dry-run 均退出码 `0`。
  本轮未启动 Webots、真实冒烟、正式训练或 TensorBoard；当前没有
  P0 Gate 通过结论。

### 根因与修复

1. 接触节点解析原先把 `Motor` 对象传给 `Supervisor.getFromDevice()`；
   当前 Webots Python 只接受整数 device tag，导致
   `foot_shank_resolution_failed` 和接触永久清零。
   现按整数 tag 回溯，并以 `fr/fl/hr/hl_shank_link` 四个精确名称校验
   唯一 `node_id`；四路任一缺失继续 fail closed。
2. 冷启动 RSI 曾返回约 `1.543 m` 首态，首个动作后约 `1.655 m`。
   现改为出生高度屈膝目标收敛，再回到权威高度 `0.2713 m`；首态必须
   满足高度 `±0.03 m`、姿态 `<=0.08 rad`、关节误差 `<=0.05 rad`，
   否则输出 `RL_RESET_TECHNICAL_FAILURE`。
3. P0/P1 评估原先硬编码 `randomization_mode="full"`；现按契约使用
   `fixed`。
4. `steps<2`、reset 高度/姿态/关节越界、非有限值或异常接触 source
   标记为 `technical_failure`，不进入物理均值；`run_stages` 对技术故障
   立即停止，不重试成有效 Gate 样本。
5. P0 改为工程 Gate，只检查四机握手、57/12、finite、奖励接口和短链路；
   P1 才执行高度、四足接触、速度、漂移和抖动等物理 Gate。P1～P6 阈值
   未放宽。
6. 当前失败状态下的 P0 checkpoint 只作污染取证；阶段调度从零启动 P0，
   历史 checkpoint 和失败日志均保留。

### 修复循环 4：固定 RSI step 数消除同步死锁

- 循环 3 冒烟通过，但正式 P0 再次在 `total_timesteps=2816` 的 reset
  等待 `180.100s` 后失败；四机日志停在 `rsi_stage_a_33`，没有
  `RL_RESET_TECHNICAL_FAILURE`，说明不是阈值或 capability 故障。
- 根因是四台同步 Webots controller 的 reset step 数不同：一台提前完成
  reset 进入 `receive()` 后不再推进仿真步，另外三台在 `robot.step(4)`
  等待，造成跨 controller 死锁，环境最终在 worker 0 上超时。
- `_hold_rsi_stage` 改为固定执行完整阶段步数后再验收，保证四台同时
  完成 reset；仍保留出生姿态固定、高度/姿态/关节误差和 180 s TCP
  有界超时，不跳过 reset、不放宽 Gate。

### P1 接触断崖平滑与四足门槛调整

- 日期：2026-10-05
- 原因：最新 P1 400,000 步仅 `true_four_contact` 失败，但 TensorBoard 在
  局部 300k 课程边界出现 `ep_rew_mean` 从约 `5402` 断崖降到 `988`、
  `true_four_contact_ratio` 从约 `0.8696` 降到 `0.5833`。取证表明四足
  奖励 `12→3`、缺足惩罚 `-1→-0.35`、静态课程关闭与 reset 扰动启用
  同时发生；动作限速和摩擦不是本次断崖主因。
- 根因与修复：
  1. P1 四足奖励在 `280,000～320,000` 步由 `12` 连续线性混合到 `3`，
     缺足惩罚同步由 `-1.0` 连续混合到 `-0.35`；P1 全程保留正四足奖励
     和负缺足惩罚，不再让接触激励在 300k 一步突然消失。
  2. `static_contact_course` 从 `300,000` 步起另用 `30,000` 步线性淡出，
     与主奖励分开过渡；`340,000` 步才启用 reset 扰动，与奖励稳定点错开
     `10,000` 步。Gate 首次触发步仍为 `310,000`。
  3. P1 `true_four_contact_ratio_min` 从 `0.95` 调整为 `0.85`，这是用户
     明确批准放宽的唯一 P1 项。依据最新 deterministic/stochastic 分别为
     `0.8611/0.8962`，`0.85` 仍要求绝大多数时间四足同时支撑；其他 Gate
     阈值、P1 总预算 `400,000`、PPO 超参和动作限速均未修改。
