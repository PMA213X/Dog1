# 2026-10-08 变更记录

## YoboGo Isaac Lab 官方键盘回放入口

- 日期：2026-10-08
- 原因：正式 checkpoint `model_4799.pt` 已生成，但官方 `play.py`
  不会自动把键盘速度写入 YoboGo 速度命令；需要独立、可 headless
  验证的回放入口，并明确人工键位验收方法。
- 涉及模块：RSL-RL checkpoint 推理、Gym 任务注册、
  `UniformVelocityCommand` 回放覆盖、Isaac Lab `Se2Keyboard`。

### 代码实现

新增唯一代码文件：

- `mini-cheetah-isaaclab/training/scripts/play_keyboard.py`

实现内容：

- 默认 CLI：
  `--task YoboGo-Velocity-Flat-v0`、最终 `model_4799.pt`、
  `--num_envs 1`、GUI 默认启动、`--smoke-steps 0`、
  可选 `--headless` 和 `--no-keyboard`；
- 复用 `_bootstrap.py`、`training.envs`、
  `YoboGoVelocityFlatEnvCfg`、`YOBOGO_MINI_CHEETAH_CFG` 和
  `OnPolicyRunner.load()`，未重写机器人模型；
- checkpoint 加载后创建 Isaac Lab 官方 `Se2Keyboard`，默认灵敏度为
  `vx=0.8 m/s`、`vy=0.4 m/s`、`yaw=1.0 rad/s`；
- 回放配置关闭 `heading_command`、heading/standing 抽样，把
  `resampling_time_range` 改为 `(1e9,1e9)`；
- 在官方 `UniformVelocityCommand.compute()` 之后写入
  `vel_command_b=[vx,vy,yaw]`，并把 `time_left` 重置为 `1e9 s`，
  保证本次观测读到回放命令；
- 写入前按环境 `[-1,1]` 范围裁剪；
- `--no-keyboard` 使用固定命令 `[0.15,0,0] m/s`；
- `--smoke-steps N` 在执行 N 次 policy/env step 后有界退出；
- `Esc` 停止交互回放，`L` 使用官方 `Se2Keyboard` 清零；
- 新增 `[STAGE]` 阶段日志，分别标记配置、环境创建、checkpoint、
  键盘初始化、事件循环和首步完成；
- GUI 模式在阶段边界及每步回放后显式调用
  `simulation_app.update()`，便于核验和维护 Kit 事件循环；
- 新增 `--record-video`、`--walk-steps`、`--walk-speed`、
  `--video-fps`、`--output`，录制模式强制 `num_envs=1`、
  `enable_cameras=True` 和固定前进命令，不依赖键盘；
- 复用官方 `gym.wrappers.RecordVideo` 与 Isaac viewport RGB 渲染，
  录制前先 `env.reset()` 并预热三次渲染，固定世界相机分辨率为
  `960×540`；
- 默认 `400` 步、`0.3 m/s`、`40 FPS`，输出约 `10 s` MP4；
  录制后检查 XY 位移至少 `0.05 m`，再校验 MP4 非空并重命名到
  `--output` 指定路径。

未修改既有训练配置、checkpoint、`YoboGo-control/`、
`official-mini-cheetah/` 和 `Cheetah-Software/`。

### 前腿运动诊断与修复

- 相机从后侧视角改为前侧视角 `eye=(-2.8,2.8,1.35)`，减少机身对
  FR/FL 的遮挡；

  min/max/RMS、position/torque clip 计数，并写入
  `rapid_walk_test.summary.leg_stats.json`；
- 新增前腿运动 Gate：FR/FL 目标 P2P 最小值须 `>=0.04 rad`，
  实际 P2P 最小值须 `>=0.05 rad`；
- 最终前腿 Gate：`front_target_range_min=0.062500 rad`、
  `front_actual_range_min=0.161632 rad`，通过；
- FR/FL 实际 P2P（HAA/hip/knee）约
  `0.427/0.303/0.162 rad`、`0.429/0.209/0.323 rad`；
- 前腿 raw 样本 `167/180`（`92.8%`）被 `±0.25` OOD 门限裁剪，
  力矩裁剪 3 次；后腿 raw 样本 `174/180`（`96.7%`）被裁剪，
  力矩裁剪 51 次。
