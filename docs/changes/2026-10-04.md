### 旧 F1 复盘结论

- 零命令站立奖励出现速度符号错误：正确形式应为负的
  `||v-cmd||²`，旧实现可能给高速度正奖励。
- 四足接触用聚合条件冒充真实四足支撑；R3 必须逐足独立判断。
- action rate、关节速度、归一化扭矩等平滑项过弱，策略会高频抖动。
- delayed action 奖励使用排队前动作而非实际执行动作，训练信号错位。
- 旧 gate 只看摔倒率和 episode 长度，门限过松，不能识别漂移、姿态峰值、
  足滑、动作抖动和 stochastic 策略退化。

### R3 累计预算

所有数值均为四台机器人共同产生的累计 transition：

| 阶段 | 累计目标 | 内容 |
| --- | ---: | --- |
| P0 | 10,000 | 工程、奖励接口和四机链路冒烟 |
| P1 | 400,000 | 纯站立；P1 内前 100,000 步（累计 10k→110k）固定 RSI，之后小扰动 |
| P2 | 1,500,000 | 低速命令 |
| P3 | 4,000,000 | 完整命令 |
| P4 | 6,500,000 | 分级 Domain Randomization |
| P5 | 9,500,000 | 原地跳 |
| P6 | 14,500,000 | 移动跳 |
| P7 | 18,000,000 | 遥控整合 |
| 缓冲 | 20,000,000 | 仅按批准使用，不自动延长阶段 |

Gate 可在预算内提前通过；到达阶段预算仍未通过即记为 `failed` 并停止，
不自动延长、不降门槛。R3 不加载旧 `450000` 或 `2000000` checkpoint，
旧 `official_mini_cheetah_flat_jump_v1_r2_2000000_steps.zip` 只作历史归档。

### R3 奖励与验收要点

- P1 命令全零、10 s episode；关闭 `feet_air_time`、步态、距离和跳跃奖励。
- RSI 高度约 `0.3889 m`、roll/pitch 约 `0`、零速度、四脚轻触地。
- 速度项统一使用负的 `||v-cmd||²`；delayed reward 使用实际执行动作。
- 接触奖励逐足独立计算；平滑、关节速度、扭矩、足滑、非足部碰撞和摔倒
  均作为独立分项。
- P2 起才逐步加入低速跟踪和轻微步态，移动奖励不得压过安全和平滑。
- P4 DR 按 reset 扰动、观测噪声、0～2 周期延迟、摩擦 ±10%、质量 ±5%、
  电机强度 ±5%、小幅外推的顺序逐级开启。
- Gate 使用 deterministic 10 集 + stochastic 10 集、稳定期和物理指标，
  每 10k transition 评估，每 20k 保存 best checkpoint。
- 训练 reward 只作趋势；最终以站立、命令跟踪、跳跃、遥控和长期稳定性
  的物理指标验收。

### R3 Play 链路

```text
InputAdapter → 57 维观测 → deterministic model.predict → 12 维关节动作
```

零命令或输入超时自动回站立；急停独立于策略。最终计划覆盖站立 30 s、
前后/横移/转向、原地跳和移动跳、输入超时、急停、连续 10 min 无崩溃。

### 初始化错误、能力降级与 height reward 修复

- controller 致命初始化分支明确输出：
  `missing_webots_controller`、`initialization_exception`、
  `timestep_mismatch`、`self_node_missing`、`robot_name_missing`、
  `worker_id_invalid`、`synchronization_failed`、`motor_device_missing`、
  `sensor_device_missing`、`device_count_mismatch`；TCP 失败输出
  `webots_connection_failed`。
- 每个分支保留 detail；预分类外异常和连接异常保留异常类型、消息和
  traceback，避免退化为无法定位的笼统错误。
- torque feedback 不可用时记录 `torque_sampling_failed`，指标源降级为
  `capability_missing_pd_fallback`，不伪造反馈值。
- contact tracking、四个具名 shank 解析或接触读取失败时 fail closed：
  四足接触/足滑清零，reward 计算前清除原始假接触，source 为
  `capability_missing_fail_closed`；未映射 shank node 不做象限猜测。
- capability 错误不阻断 controller 初始化；RSI 屈膝目标设置、保持和
  恢复继续执行，不因指标能力缺失而跳过。
- `height` reward 修正为负权重乘平方误差：目标高度为 `0`，高于或低于
  目标均为负值；新增参考高度、偏高和偏低三个方向的符号测试。

### 单 World 四机架构

- 唯一训练 world 内含四个完整 Robot：`mini_cheetah_0..3`，出生点为
  `(-4,-4,0.45)`、`(4,-4,0.45)`、`(-4,4,0.45)`、`(4,4,0.45)`。
- 四个 Robot 均使用 `controller "<extern>"`、`synchronization TRUE`、
  `supervisor TRUE`；唯一 Webots 实例使用端口 `1234`。
- TCP 端口固定为 `11452`、`11453`、`11454`、`11455`，与四台机器人一一对应。
- `SharedWorldVecEnv` 先批量发送四路 `reset/act`，再统一接收；任何机器人
  自然结束时，四台统一 reset。关闭时先回收四路 controller，再关闭唯一
  Webots，避免孤儿进程。
- 越界判断以各自出生点为中心，局部活动半径为 `3 m`。
- 每次四路 reset 只采样并共享一次全局摩擦；质量缩放、动作延迟和各类
  episode RNG 按机器人独立随机化。
- 历史评估使用单机器人 `flat_move_jump_rl_eval.wbt`，当时不改变
  F1/F2R/F3 的 10 集 gate 语义和门槛。
