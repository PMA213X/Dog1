## 3. 已实施的安全说明

- 启动日志应显示解析后的绝对 checkpoint 路径；
- 1 秒稳定窗口为 50 Hz 下 50 个控制周期；
- 放行前要求连续 10 个控制周期四足均接触，100 个控制周期仍未满足则停止 play；
- `raw` 动作先裁剪到 `[-0.5, 0.5]`，`safe` 动作每周期相对上一安全动作变化不超过 `0.05`；
- 机身高度超过 `0.600 m` 时判定为异常离地并停止 play；
- `parkour_dev.wbt` 只保留 `DEF VP_FOLLOW` 一个 `Viewpoint`。

## 6. 单关节顺序扫描测试说明

- 启动期低空弹射的主根因不是重力：本 world 未覆盖 `WorldInfo.gravity`，
  仍使用 Webots 正常向下重力。只读 A/B 保持出生位姿、控制器、接触参数和
  其余物理设置不变，唯一变量为 Robot 的 `selfCollision`：
  `TRUE` 时触地后低空弹射并出现位置跟踪超时，`FALSE` 时正常落地且无超时；
- 源 world 因此固定为 `selfCollision FALSE`，静态测试同时断言 `FALSE` 且
  禁止重新出现 `TRUE`；这个开关规避了内部接触，因此当前扫描世界**不验证
  机器人部件间自碰撞**，如需验证应另建隔离用例；
- 原仰躺出生高度 `0.10 m` 会让局部碰撞几何最低点穿入地面上方 `z=0`
  约 `0.042 m`；修复后出生高度提高到 `0.15 m`，并显式配置
  `default/default` 的 `coulombFriction 0.8`、`softERP 0.2`、
  `softCFM 0.001`、`bounce 0`、`bounceVelocity 0`；
- 新 world 使用仰躺姿态，机器人不承担站立或平衡任务，只检查关节设备映射、
  固定顺序和停止链路；
- 控制器一次只驱动一个关节，按 `0 → min → 0 → max → 0` 执行，
  速度上限 `0.20 rad/s`，`min` 和 `max` 实际到位后各停留 `0.5 s`；
- 位置跟踪误差超过 `0.05 rad` 并连续持续 `10 s` 时停止，未执行关节不再
  继续，全部电机保持当前实际位置；序列没有固定总时长；
- 12 个关节全部完成且实际位置全部进入 `±0.05 rad`，才输出
  “关节扫掠完成，已全部回零”；
- `Esc` 与 `R` 均可立即停止当前序列，停止后不打印正常完成信息，且不会
  自动恢复；
- GUI 固定启动命令：

```bash
/usr/local/webots/webots --mode=realtime --stdout --stderr webots-sim/worlds/joint_sweep_test.wbt
```

- 批量验收命令：

```bash
DISPLAY=:0 timeout 300s /usr/local/webots/webots --batch --mode=fast --stdout --stderr webots-sim/worlds/joint_sweep_test.wbt
```

- 控制器单测命令：

```bash
python3 -m unittest discover -s webots-sim/controllers/joint_sweep_test -p 'test_*.py'
```

- world 静态测试命令：

```bash
python3 -m unittest discover -s webots-sim/rl/tests -p 'test_*.py'
```

- world 静态验收必须同时确认唯一 `default/default` 接触对的
  `coulombFriction 0.8`、`softERP 0.2`、`softCFM 0.001`、
  `bounce 0`、`bounceVelocity 0`，以及出生参数
  `translation 0 0 0.15`、`rotation 1 0 0 1.5708`、
  `selfCollision FALSE`；
- 该测试不读取 checkpoint、不加载 Stable-Baselines3 模型、不建立 TCP 连接；
- 不修改训练入口、观测/动作/奖励、checkpoint 或 `parkour_dev.wbt`；
- 扫描完成只表示设备顺序与停止链路通过，不表示模型、步态、跑酷或实机验收通过。
