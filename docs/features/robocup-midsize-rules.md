## 1. 概述

### 1.1 赛事背景

RoboCup中型组（Middle Size League，简称MSL）是RoboCup机器人世界杯足球赛的一个组别，其核心目标是推动全自主足球机器人的研究与发展。中型组比赛由两支各5台自主机器人的球队在矩形场地上进行足球比赛，所有机器人必须完全自主运行，不允许赛中人工干预。

### 1.2 比赛宗旨

1. **完全自主**：比赛中所有机器人必须自主运行，不允许人类远程操控。
2. **技术创新**：推动多机器人协作、实时感知、路径规划、决策控制等人工智能与机器人技术的发展。
3. **公平竞争**：规则旨在确保比赛公平进行，鼓励技术创新而非单纯追求规则漏洞。
4. **全自主足球**：最终目标是在2050年前开发出能与人类世界杯冠军抗衡的全自主机器人足球队。

### 1.3 赛事组织

- **国际赛事**: RoboCup 2026 Middle Size League — 2026年6月30日至7月6日，韩国仁川Songdo Convensia
- **中国赛**: 2026中国机器人大赛暨RoboCup机器人世界杯中国赛
  - RoboCup赛区（含中型组足球比赛）
  - 中国机器人大赛赛区
- **主办单位**: 中国自动化学会（CAA）、中国自动化学会机器人竞赛与培训部
- **官方网址**: https://msl.robocup.org / https://rcccaa.drct-caa.org.cn

## 2. 比赛场地

### 2.1 场地尺寸

| 项目 | 正式比赛 | 本地/区域比赛（可选） |
|------|----------|----------------------|
| 长度 | **22米** | 18米 |
| 宽度 | **14米** | 12米 |

> **来源**: MSL Rulebook 2025 v26.0 / Grokipedia RoboCup Middle Size League

### 2.2 场地表面

- 场地表面为**平整绿色地毯**，由当地组织者提供
- 地毯表面不得有凸起或不规则之处
- 场地内照明由组织者提供，须确保足够亮度

### 2.3 场地标线

| 项目 | 规格 |
|------|------|
| 标线颜色 | **白色** |
| 标线宽度 | **12.5厘米**（125mm） |
| 测量基准 | 从标线外沿测量 |

### 2.4 球门

| 项目 | 规格 |
|------|------|
| 位置 | 每条球门线中央 |
| 立柱内距 | **2.44米** |
| 横梁下沿高度 | **2.0米** |
| 立柱宽度 | ≤12厘米 |
| 横梁宽度 | ≤12厘米 |
| 球门深度 | ≥0.5米 |
| 颜色 | **白色** |
| 球网 | 延伸至安全边界，底部覆盖30-40厘米 |

### 2.5 安全边界

- 场地四周设有**黑色安全边界**（挡板），高度8-15厘米
- 安全边界距边线和球门线**至少1米**
- 防止机器人进入观众区域

### 2.6 场地区域划分

| 区域 | 尺寸（距球门柱内沿/球门线） |
|------|---------------------------|
| 球门区（Goal Area） | 纵深0.75米，宽距柱内沿各0.75米 |
| 罚球区（Penalty Area） | 纵深2.25米，宽距柱内沿各2.25米 |
| 罚球点（Penalty Mark） | 距球门线中点3.6米 |
| 角球弧（Corner Arc） | 半径0.75米的四分之一圆 |
| 中圈（Center Circle） | 半径**2米** |
| 中心点（Center Spot） | 直径15厘米，白色 |

### 2.7 旗杆

- 场地四角及半场线与边线交点处放置**旗杆**
- 旗杆用于辅助定位和边界标识

> **来源**: MSL Rulebook v26.0, 规则1 - 比赛场地要求

## 3. 比赛用球

### 3.1 球的规格

| 项目 | 规格 |
|------|------|
| 类型 | 标准FIFA 5号球（足球） |
| 形状 | 球形 |
| 圆周 | **68-70厘米** |
| 重量 | **410-450克** |
| 气压 | **0.6-1.1大气压** |

### 3.2 球的颜色

- 球的颜色应避免以**黑色、白色或绿色**为主色调
- 目的是便于机器人视觉系统识别

### 3.3 球的替换

- 当球损坏或变形影响正常比赛时，裁判可决定替换球
- 比赛中断期间进行球的更换

> **来源**: MSL Rulebook v26.0, 规则2 - 比赛所用球; Grokipedia

## 4. 机器人规格要求

### 4.1 尺寸限制

| 项目 | 要求 |
|------|------|
| 底面积（投影） | ≤ **52cm × 52cm** |
| 最小配置 | ≥ 30cm × 30cm |
| 高度 | **40cm - 80cm** |
| 60cm以上部分 | 须在直径**25cm**圆柱体内 |
| 重量 | ≤ **40千克**（含1千克误差容限） |

### 4.2 守门员特殊规格

| 项目 | 守门员特殊允许 |
|------|---------------|
| 防守时底面积 | 可临时扩展至**60cm × 60cm** |
| 防守时高度 | 可临时达到**90cm** |
| 扩展持续时间 | ≤ **1秒** |
| 再次使用间隔 | **4秒**冷却期 |

### 4.3 外观要求

| 项目 | 要求 |
|------|------|
| 机身颜色 | **哑光黑色**，减少反光 |
| 安全边框 | 连续软质安全边框，厚度≥1cm，高度≥6cm |
| 安全边框后部 | 须完全支撑 |
| 射门机构 | 须安全，不得损坏球 |
| 表面 | 不得有闪亮或高反光表面 |

### 4.4 机器人标识

| 项目 | 要求 |
|------|------|
| 号码 | 守门员须标号"1" |
| 颜色面板 | 用于区分队伍（如粉/青区分双方队伍） |

### 4.5 供电方式

- 机器人必须为**电池供电**
- 电池容量无明确上限
- 必须具备**紧急停止功能**，能立即停止所有执行器

> **来源**: MSL Rulebook v26.0, 规则3 - 比赛队员装备; Grokipedia; 知乎Zhihu

## 5. 队伍组成与参赛要求

### 5.1 国际赛（MSL World Championships）

| 项目 | 要求 |
|------|------|
| 每队场上机器人 | **5台**（4名场上球员 + 1名守门员） |
| 替换机器人 | 每场最多**3次** |
| 最低参赛机器人 | 每队至少**2台**可用机器人才能开赛 |
| 人员 | 领队、技术人员等（具体人数参照规则） |
| 混合队伍 | 允许，需赛前声明 |

### 5.2 中国赛 — RoboCup赛区

| 项目 | 要求 |
|------|------|
| 指导教师 | ≤ 3人 |
| 学生 | ≤ 15人 |
| 晋级方式 | 校赛（前25%）→ 国赛 |
| 同一高校同一子项目 | 校赛晋级至国赛队伍数 ≤ 5支 |

> **来源**: 山东师范大学校赛通知; 郑州大学校赛通知; 2026中国机器人大赛通知

### 5.3 资格审核

参赛队伍需提交以下资格材料：

1. **队伍描述论文（TDP）** — 8页以内，LNCS格式，描述最具创新性的贡献
2. **5篇科学论文** — 近5年内发表的与RoboCup相关的论文
3. **近三年的成绩与奖项**
4. **能力展示视频** — 最长60秒，展示机器人基本比赛能力
5. **对MSL社区的贡献清单**
6. **混合队伍声明**
7. **机械和电气描述 + 软件流程图**
8. **MAC地址清单**
9. **机器人尺寸和重量清单**

> **来源**: 2026 MSL Call for Participation

## 6. 比赛时长与赛制

### 6.1 比赛时间

| 项目 | 规格 |
|------|------|
| 上半场 | **15分钟**（净比赛时间） |
| 下半场 | **15分钟**（净比赛时间） |
| 中场休息 | ≤ **10分钟** |
| 计时方式 | **时钟时间** |

### 6.2 淘汰赛加时

| 项目 | 规格 |
|------|------|
| 加时赛上半场 | **5分钟** |
| 加时赛下半场 | **5分钟** |
| 额外换人 | 每队可增加1次换人机会 |
| 点球大战 | 加时赛后仍平局则进行点球大战 |

### 6.3 赛制安排

| 阶段 | 说明 |
|------|------|
| 小组赛 | 循环赛制，积分决定排名 |
| 淘汰赛 | 淘汰制（可能含加时和点球） |
| 人机对抗赛 | 可能安排人机混合对抗赛 |

### 6.4 有效比赛时间监控

- 从2026年起，组织者将**监控有效比赛时间**
- 目标是减少比赛中断时间，提升比赛观赏性

## 7. 比赛规则与判罚

### 7.1 基本规则

- 比赛基于**FIFA足球规则的修改版**
- **没有越位规则**（No offside）
- 比赛以全自主方式进行，不允许人类干预

### 7.2 比赛开始与重新开始

| 情况 | 操作 |
|------|------|
| 开球 | 在中心点开球 |
| 任意球 | 从犯规发生地点罚球，对方退后**至少1米** |
| 球移动后即为活球 | 球移动**50厘米**后即为活球 |
| 重新开始时限 | 必须在**7秒**内执行，否则对方可拦截 |

### 7.3 持球规则

| 项目 | 规格 |
|------|------|
| 持球时间限制 | ≤ **5秒**（超过则判间接任意球） |
| 守门员持球 | 罚球区内持球 ≤ 5秒 |

### 7.4 进球规则

- 球整体越过球门线，在两立柱之间及横梁下方即为进球
- 进球须由合法踢球产生
- 远程操控或无效吊射不算进球

### 7.5 点球大战规则

| 项目 | 规格 |
|------|------|
| 主罚距离 | **3.6米** |
| 轮次 | 5轮交替主罚 |
| 守门员 | 面对点球射门 |
| 平局处理 | 5轮后平局则突然死亡 |

> **来源**: MSL Rulebook v26.0; Grokipedia

## 8. 犯规与处罚

### 8.1 常见犯规类型

| 犯规类型 | 处罚 |
|---------|------|
| **持球超时**（>5秒无进展） | 间接任意球 |
| **推挤**（物理接触导致对方失控） | 间接任意球 |
| **非法防守**（罚球区内超过1台机器人超10秒） | 间接任意球 |
| **非法进攻**（对方罚球区内超过1台机器人超10秒） | 间接任意球 |
| **故意推挤**（罚球区内） | 点球 |
| **恶意犯规** | 黄牌/红牌 |

### 8.2 黄牌与红牌

| 处罚 | 含义 |
|------|------|
| **黄牌** | 警告，累计两张黄牌 → 该机器人被罚下场**90秒** |
| **红牌** | 直接驱逐，机器人永久退场（暴力行为或累计犯规） |

### 8.3 弃权与退出

- 弃权或退出比赛，对方获 **3-0** 胜利或等效进球优势

> **来源**: MSL Rulebook v26.0; Grokipedia

## 9. 裁判系统

### 9.1 人工裁判

- 比赛由**人类裁判**执法
- 配有助理裁判协助
- 裁判具有最高权威

### 9.2 裁判盒（RefBox）

| 项目 | 说明 |
|------|------|
| 功能 | 将裁判决定发送给机器人 |
| 比赛时间控制 | 统一计时和比赛记录 |
| 通信方式 | 通过专用系统发送裁判指令 |

### 9.3 裁判权限

- 裁判可以暂停比赛
- 裁判可以决定替换球
- 裁判可以判定犯规和处罚
- 裁判的最终决定具有权威性

> **来源**: MSL Rulebook v26.0, 规则4 - 裁判及助理裁判

## 10. 通信与网络

### 10.1 通信标准

| 项目 | 要求 |
|------|------|
| 无线标准 | **IEEE 802.11**（b/g/n/ac/ax） |
| 接入点 | 由组织者提供 |
| 对等网络（Ad-hoc） | **禁止** |
| 广播传输 | **禁止**（使用组播） |
| 非标准频率 | **禁止** |

### 10.2 带宽限制

| 项目 | 限制 |
|------|------|
| 带宽使用 | ≤ 接入点带宽的**20%**（约2.2 Mbps） |
| 发射功率 | 接收信号强度上限 **-45 dBm** |

### 10.3 通信规则

- 禁止敌对队伍机器人之间通信
- 禁止干扰对方通信或传感器
- 违反通信规则可导致取消比赛资格
- 使用的MAC地址须提前注册

> **来源**: MSL Rulebook v26.0; Grokipedia

## 11. 视觉与传感器系统

### 11.1 视觉系统限制

| 项目 | 要求 |
|------|------|
| 全局视觉系统 | **禁止**（禁止使用场地顶部摄像头） |
| 车载视觉 | 所有感知须在机器人上完成 |
| 相机类型 | 全向相机（catadioptric）、多摄像头系统等 |

### 11.2 传感器使用

- 在不违反其他规则的情况下，对机器人传感器的类型与数量**没有限制**
- 常用传感器包括：
  - 全向摄像头
  - LiDAR / 深度相机（如Kinect、RealSense）
  - 惯性测量单元（IMU）
  - 轮式编码器
  - 超声波传感器

### 11.3 视觉处理要求

- 所有视觉处理须在机器人**车载计算平台**上完成
- 不允许使用外部计算辅助感知
- 典型视觉处理频率：30-60 Hz

> **来源**: MSL Rulebook v26.0; Grokipedia; Zhihu技术分析

## 12. 安全要求

### 12.1 紧急停止

| 项目 | 要求 |
|------|------|
| 机器人本体急停 | 每台机器人须有**车载紧急停止按钮** |
| 无线急停 | 团队须提供**无线遥控紧急停止**装置 |
| 无线急停频率 | 不得使用WiFi频率 |
| 功能 | 能立即停止所有执行器 |

### 12.2 碰撞安全

- 机器人须能检测并避免高速碰撞
- 接触前应**明显减速**
- 不得故意撞击场地边界、球门或其他机器人
- 必须配备软质安全边框

### 12.3 技术检查

- 赛前须通过技术检查
- 不符合安全要求的机器人不得参赛
- 检查内容包括：尺寸、重量、急停功能、安全边框等

> **来源**: MSL Rulebook v26.0; Grokipedia

## 13. 技术挑战赛

### 13.1 挑战赛类型

MSL比赛除足球赛外，还设有以下技术挑战赛：

| 挑战赛 | 说明 |
|--------|------|
| **技术挑战赛**（Technical Challenge） | 评估机器人在特定技术场景下的表现 |
| **科学挑战赛**（Scientific Challenge） | 评估队伍的科研贡献和技术创新 |
| **雄心挑战赛**（Ambition Challenge） | 为新兴队伍提供的展示平台 |

### 13.2 技术挑战赛内容

- 障碍物回避
- 人机混合对抗赛（2026年起至少1场/队）
- 多种球的适应能力
- 不同光照条件下的适应性
- 机器人之间的协作配合

### 13.3 科学挑战赛评分

- 基于队伍提交的资格材料
- 包括TDP质量、论文影响、社区贡献等
- 科学挑战赛成绩计入总排名

> **来源**: MSL Rulebook v26.0; MSL History

## 14. 2026年度规则变化

### 14.1 国际赛（MSL 2026）

根据MSL技术委员会的公告：

> **"MSL Technical Committee will not publish new rules for 2026, therefore the rules from 2025 (version 26.0) will be used."**

即2026年国际赛沿用2025年规则（v26.0），未发布新规则。

### 14.2 2025/2026 Roadmap中的变化方向

根据MSL Roadmap v1.0（2025年6月发布），以下变化正在推进中：

| 变化方向 | 时间线 | 说明 |
|---------|--------|------|
| 多种球适应 | 2026年 | 从5种球中随机选择，赛前公布照片和否决权 |
| 人机对抗赛 | 2026年起 | 每队至少参加1场人机对抗，注重安全 |
| 有效比赛时间监控 | 2026年起 | 监控并减少比赛中断时间 |
| 门将特殊设计 | 2026年起 | 允许门将使用替代设计（体积0.036-0.2 m³，开源检测算法） |
| 技术挑战赛加分 | 2026年起 | 多样化光照解决方案可获额外技术挑战赛加分 |
| 亚光单色外观 | 2026年起 | 所有机器人须为亚光单色外观 |

### 14.3 中国赛变化（2026年度）

## 15. 中国赛特殊规则

### 15.1 赛项设置

2026年RoboCup足球机器人比赛包含以下子项：

| 子项 | 说明 |

| **仿真3D组** | 三维仿真足球 |
| **小型组** | 小型机器人足球 |
| **标准平台组** | 统一平台机器人足球 |

| 项目 | 规格 |
|------|------|
| 晋级比例 | 校赛前**25%** |
| 同校同项目上限 | ≤ **5支**队伍 |
| 校赛时间 | 各高校自定（通常在3-5月） |
| 国赛时间 | 2026年5月（第一轮），具体日期见通知 |

- 面向全国高校在校本科生、研究生
- 允许跨专业组建团队
- 指导教师不超过规定人数（中型组≤3人）

### 15.4 比赛地点

- 国赛地点由组委会统一安排
- 2025年第一轮比赛在北京怀柔区举办
- 2026年具体地点待组委会通知
