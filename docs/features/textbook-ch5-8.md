# 第5章 四足机器人步态规划理论与知识

## 5.1 步态规划的基本概念

### 1. 步态基本定义

动物的运动具有多样性，表现为每一种动物都具有多种运动形式，如双足动物的"走"、"跑"，四足动物的"行走(walk)"、"对角小跑(trot)"、"遛步(pace，又称单侧小跑)"、"跳跃(bound)"和"奔跑(gallop)"等，因此，相应的仿生四足机器人也有较多的步行方法。

四足机器人的步行方法一般根据摆动腿的顺序和时序进行分类，一般用步态周期、步态长度、占空比、相对位移等概念来对步态进行定义。

- **(1) 步态(gait)**：有关腿部摆动顺序及其时间相序等的步行模式。一般分为行走、对角小跑、遛步、跳跃和奔跑5种基本步态。
- **(2) 步行周期 (walking period)**：周期步态中某一条腿运动一个完整循环所需的时间。
- **(3) 支撑相(supporting phase)**：腿部着地的状态称为支撑相。
- **(4) 摆动相(swinging phase)**：腿部处于空中的状态称为摆动相。
- **(5) 支撑多边形(support polygon)**：支撑腿着地点由凸形轮廓线所构成的凸多边形在水平面上的投影。
- **(6) 静态步行(static walk)**：机器人合成质心在水平面上的垂直投影点处于支撑多边形内的状态称为静态稳定状态；始终保持静态稳定状态的步行称为静态步行。
- **(7) 动态步行(dynamic walk)、准动态步行(quasi-dynamic walk)**：步行过程中某段时间不能保持静态稳定状态的步行称为准动态步行；步行中完全不能处于静态稳定状态的持续步行称为动态步行。
- **(8) 跨步(stride)**：腿部的周期运动称为跨步。
- **(9) 步长(stride length)**：单位周期内质心的移动距离称为步长。
- **(10) 占空系数(duty factor)**：在单位跨步运动中，某条腿着地时间与步行周期之比称为占空系数。
- **(11) 稳定裕量(stability margin)**：机器人质心在水平面上的垂直投影点到支撑多边形各边的最短距离称为该时刻的稳定裕量。对于某一种周期性步态，在步行周期中稳定裕量的最小值称为步态的稳定裕量。
- **(12) 脚行程(step length、stroke length)**：处于支撑相时，摆动腿足端相对于机体移动的距离，也称为步幅。
- **(13) 规则步态**：所有腿的占空系数都相等的步态称为规则步态。

四足机器人的各种步态，一般可以根据占空系数将步态分为静步态和动步态。静步态的占空比一般满足 > 0.5，动步态占空比一般满足 ≤ 0.5。再具体分，静步态主要是指行走步态，而动步态可以分为对角小跑步态、遛步步态、跳跃步态和奔跑步态等。

### 步态类型说明

- **行走步态**：是一种静步态，任意时刻至少有三条腿着地。
- **对角小跑步态**：处于对角线上的两条腿同时摆动的动步态，一对腿处于支撑相，另一对腿处于摆动相。
- **遛步步态**：与对角小跑步态不同的是，使用身体同一侧的双腿同时摆动，另一侧的双腿处于支撑相。
- **跳跃步态**：前后腿交替动作的步态，运动过程中躯干会有明显的俯仰运动。
- **奔跑步态**：与跳跃步态的不同之处在于其先前双腿先后着地，再后双腿先后着地。

### 步态分类

根据机器人的步态周期是否固定，可将步态分为**周期步态**和**非周期步态(自由步态)**。

对于机器人来说，当其所处的环境比较复杂时（如地面崎岖不平或者有障碍物时），需要根据机器人所处的环境来进行步态的选择和运动的规划。若步态运动的周期性被打破，则称其为非周期步态。

- **连续步态**：在四足机器人的行走过程中，如果身体始终保持一个恒定的速度运动，则称为连续步态。
- **非连续步态**：否则称为非连续步态。
- **直行步态**（前进步态或后退步态）
- **转弯步态**：根据旋转半径的不同，可分为旋转(spinning)步态和环绕(circling)步态。

## 5.2 静步态规划方法

机器人的运动可视为腿部触地和离地事件的组合序列，将每条腿的落地和悬空视为事件，则机器人的腿存在落地和悬空两种状态。

- **非奇异步态**：同一条腿不同时发生相同事件的步态。
- **奇异步态**：同一条腿同时发生相同事件的步态。

对于具有k条腿的机器人来说，共有 k! 种非奇异步态，对于四足机器人来说，若每条腿每个周期只抬落各一次，共存在**5040种非奇异步态**。

所谓静步态，一般是指机器人在运动过程中，至少有3条以上的支撑腿，或者说，机器人同时至少有3条腿处于支撑相。

### 直行步态分类

根据机器人4条腿迈步顺序的不同，直行步态可分为：
- **X-方向直行步态**：从后向前的方向
- **RX-方向直行步态**：从前向后的方向
- **Y-方向直行步态**
- **RY-方向直行步态**

### 转弯步态

- **O-Rotation步态**：四足机器人逆时针的转弯步态
- **RO-Rotation步态**：四足机器人顺时针的转弯步态

在上面的6种非奇异步态当中，只有3种能保证静态稳定，而能够使稳定裕度最大化的步态只有1种，称为**匍匐静步态**。

## 5.3 动步态规划方法

四足机器人在运动过程中，为了高效率地完成给定任务，一般采用具有较好动态特性的动步态运动模式。动步态一般分为对角小跑、遛步、跳跃和奔跑，它们属于两条腿同时摆动且占空比≤0.5的步态，且运动速度按照上述顺序越来越快。

### 对角小跑步态的优势

与其他动步态相比，对角小跑步态是一种更具有实用性的动步态，理由如下：

(1) 对角小跑步态具有较高的能效和较大的速度适应范围，即使对角线上的两条支撑腿翻倒，借助于另一对角线上两条摆动腿的快速触地也可防止机器人整体翻倒。

(2) 在对角小跑步态中，对角线上前、后腿运动相位相同，理论上能同时触地和离地，易于实现机器人步行运动的对称性，保持机器人运动的自稳定性，减轻机器人姿态控制的负担，减少稳定调节过程中的动作次数。

(3) 对角小跑步态与直行步态的适配性好，仅改变占空比（从占空比为0.75的直行步态到占空比为0.5的对角小跑步态）就能连续生成与目标速度相适应的步态，有利于步态之间平滑切换的实现，可提高四足机器人的环境适应性。

因此，在机器人的步态规划中，一般都采用具有良好动态稳定性的对角小跑步态。

## 5.4 机器人轨迹规划与步态生成

### 5.4.1 机器人轨迹规划

常见的机器人作业有点到点作业和连续路径作业。机器人在运动过程中，需要进行运动轨迹的规划，这里所谓的轨迹是指机械手或者机器人在运动过程中的位姿、速度和加速度。

机器人的轨迹规划一般要求对于选定的轨迹节点(插值点)上的位姿、速度和加速度给出一组显式约束(如连续性和光滑程度等)，轨迹规划器从一类函数(如n次多项式)选取参数化轨迹，对节点进行插值，并满足约束条件。

#### 1. 三次多项式插值方法

在三次多项式插值方法中，只给定机器人运动的起始点和终止点的关节角度即可，中间可以生成多个三次多项式曲线。

三次多项式函数可以用式(5.1)表示：

$$\theta(t) = a_0 + a_1 t + a_2 t^2 + a_3 t^3 \quad (5.1)$$

其中，$a_0, a_1, a_2, a_3$ 是4个待定系数，可以由起始点和终止点两点的函数值及其一阶导数列出4个方程，进而求出4个系数。

机器人为了实现平稳运动，其轨迹函数的4个约束条件定义如下：
- (1) 满足起始点关节角度约束：$\theta(0) = \theta_0$
- (2) 满足终止点关节角度约束：$\theta(t_f) = \theta_f$
- (3) 满足起始点关节速度约束：$\dot{\theta}(0) = 0$
- (4) 满足终止点关节速度约束：$\dot{\theta}(t_f) = 0$

将约束条件代入式(5.1)，可得：

$$a_0 = \theta_0, \quad a_1 = 0, \quad a_2 = \frac{3}{t_f^2}(\theta_f - \theta_0), \quad a_3 = -\frac{2}{t_f^3}(\theta_f - \theta_0) \quad (5.2)$$

**例1**：设1自由度的旋转关节机械手处于静止状态时，$\theta_0 = 10°$，要在 $t_f = 2s$ 内平稳运动到达终止位置 $\theta_f = 90°$，并且在终止点的速度为零，求该机械手的关节角度约束和速度约束。

解：将已知条件代入式(5.2)可得：
$a_0 = 10°$，$a_1 = 0$，$a_2 = 120$，$a_3 = -80$

#### 2. 过路径点的三次多项式插值

机器人在运动过程中，有时候有些特殊要求，如抬腿结束和落地开始要保证平滑或者加速度为0。该方法把所有路径点都看成起始点或终止点，求解逆运动学方程，得到相应的机器人关节矢量值。

利用约束条件和式(2)同理可以求得此时的三次多项式系数：

$$a_0 = \theta_0, \quad a_1 = \dot{\theta}_0, \quad a_2 = \frac{3}{t_f^2}(\theta_f - \theta_0) - \frac{2}{t_f}\dot{\theta}_0 - \frac{1}{t_f}\dot{\theta}_f, \quad a_3 = -\frac{2}{t_f^3}(\theta_f - \theta_0) + \frac{1}{t_f^2}(\dot{\theta}_0 + \dot{\theta}_f) \quad (5.3)$$

计算路径点上的关节速度有3种方法：
1. 根据工具坐标系在直角坐标空间中的瞬时线速度和角速度来确定每个路径点的关节速度。
2. 为了保证每个路径点上的加速度连续，由控制系统按照此要求自动地选择路径点的关节速度。
3. 在直角坐标空间或关节空间中采用某种适当的启发式方法，由控制系统自动地选择路径点的关节速度。

如果对运动轨迹的要求更为严格，约束条件增多，那么三次多项式就不能满足需要，必须用更高阶的多项式对运动轨迹的路径段进行插值。例如，对某段路径的起始点和终止点都规定了关节的位置、速度和加速度（有6个未知系数），则要用一个**五次多项式**进行插值。

#### 3. 用抛物线过渡的线性插值

单纯线性插值将导致在节点处关节运动速度不连续，加速度无限大。为了解决上述问题，使用线性插值时，在每个节点的邻域内增加一段抛物线的"缓冲区段"，从而使整个轨迹上的位移和速度都连续。

#### 4. 过路径点的用抛物线过渡的线性插值

某个关节在运动中设有 n 个路径点，其中三个相邻的路径点表示为 $\theta_1$，$\theta_2$ 和 $\theta_3$，每两个相邻的路径点之间都以线性函数相连，而所有的路径点附近则由抛物线过渡。

#### 5. 带"伪节点"的线性插值

当要求机器人通过某个节点且速度不为零时，常采用此方法。此方法在节点两端规定两个"伪节点"，令原节点在两伪节点的连线上，并位于两过渡域之间的线性域上。

### 5.4.2 机器人步态生成方法

向前行走是四足机器人移动控制最基本的问题，最常见的是基于足端轨迹规划的向前行走方法。足端轨迹规划的基本要求：
- (1) 轨迹连续
- (2) 速度连续
- (3) 摆动腿在触地前即开始后撤
- (4) 支撑腿在离地后仍后撤一段距离
- (5) 支撑相速度基本恒定

常见的四足机器人的步态生成方法有三次曲线法、复合摆线法、改进复合摆线法和三次贝塞尔曲线规划法等。

#### 1. 三次曲线法

在三次曲线法中，利用三次多项式对机器人的步态进行规划。一般分别单独规划前进方向(x轴)和上下方向(z轴)的足端运动轨迹。

**x轴方向的步态运动**：前半个周期[0,0.5T]为支撑相，后半个周期(0.5T,T)为摆动相。支撑相的足端轨迹为直线，摆动相使用三次多项式曲线：

$$x = \begin{cases} \frac{S}{2}(1 - \frac{2t}{T}) & 0 \leq t \leq \frac{T}{2} \\ \frac{S}{2}(-1 + \frac{2(2t-T)}{T} - \frac{(2t-T)^2}{T^2}) & \frac{T}{2} < t \leq T \end{cases} \quad (5.4)$$

其中，S表示四足机器人行走过程中的腿摆幅，t是当前周期流逝的时间，T表示一个完整步态周期总时间。

**z轴方向的步态运动**：支撑相速度为恒定值，摆动相使用余弦曲线：

$$z = \begin{cases} 0 & 0 \leq t \leq \frac{T}{2} \\ H\sin(\frac{\pi(2t-T)}{T}) & \frac{T}{2} < t \leq T \end{cases} \quad (5.5)$$

其中，H表示跨步高度。可以根据地面的不平坦程度和机器人运动速度的需求修改参数S、H和T以实现对机器人步长、步高和步频的控制。

#### 2. 复合摆线法

复合摆线法将数学中的摆线方程引入足端轨迹的规划中，满足在机器人抬腿和落地瞬间实现零冲击和落地软着陆，关节速度和加速度变化平滑、连续、无奇点。

假设在摆动腿周期和站姿周期之间的连接点处速度为0，定义：

$$\dot{x} = v_{max}\sin(\frac{\pi t}{t_s}) \quad (5.6)$$

其中，$v_{max}$ 为待定参数，$t_s$ 为摆动腿摆动时间，$T$ 为步行时间。

由上式可得关于速度的表达式：

$$\dot{x} = v_{max}\sin(\frac{\pi t}{t_s}) \quad (5.7)$$

对式(5.4)中的 $\dot{x}$ 进行积分，可得机器人步态规划的位置表达式：

$$x = \int_0^t \dot{x}dt = \frac{v_{max}t_s}{\pi}(1 - \cos(\frac{\pi t}{t_s})) \quad (5.8)$$

当 $t = 0$ 时，$x = 0$；当 $t = t_s$ 时，$x = S$。有：

$$S = \frac{2v_{max}t_s}{\pi} \quad (5.9)$$

其中S为步长。将式(5.9)代入式(5.6)～式(5.8)中，依次得到：

$$x = \frac{S}{2\pi}(\pi t - t_s\sin(\frac{\pi t}{t_s})) \quad (5.10)$$

$$\dot{x} = \frac{S}{2t_s}(1 - \cos(\frac{\pi t}{t_s})) \quad (5.11)$$

$$\ddot{x} = \frac{\pi S}{2t_s^2}\sin(\frac{\pi t}{t_s}) \quad (5.12)$$

在z轴运动中，设定足端运动的边界条件，使在出发点、最大足端高度和落地点的加速度和速度为0。将脚重复撞击地面的周期性运动视为凸轮轴的一种垂直运动，加速度呈正弦规律变化：

$$\ddot{z} = a_{max}\sin(\frac{2\pi t}{t_s}) \quad (5.13)$$

速度是通过对式(5.13)进行积分得到的：

$$\dot{z} = \frac{a_{max}t_s}{2\pi}(1 - \cos(\frac{2\pi t}{t_s})) \quad (5.14)$$

位置是由式(5.14)对t积分得到的：

$$z = \frac{a_{max}t_s}{2\pi}(t - \frac{t_s}{2\pi}\sin(\frac{2\pi t}{t_s})) \quad (5.15)$$

$$z_{max} = \frac{a_{max}t_s^2}{4\pi^2} \quad (5.16)$$

将式(5.16)代入式(5.13)～式(5.15)中，得到：

$$\ddot{z} = \frac{4\pi^2 H}{t_s^2}\sin(\frac{2\pi t}{t_s}) \quad (5.17)$$

$$\dot{z} = \frac{2\pi H}{t_s}(1 - \cos(\frac{2\pi t}{t_s})) \quad (5.18)$$

$$z = H(\frac{2\pi t}{t_s} - \sin(\frac{2\pi t}{t_s})) \quad (5.19)$$

#### 3. 改进复合摆线法

为了防止当足底与地面接触时产生滑动，在步态规划中，摆动腿的抬腿速度和落地速度均为0。为了防止机器人行走过程中产生拖地现象，仅在x轴方向(机器人前进方向)步态规划中采用复合摆线的形式。修改后的四足机器人摆动腿的步态规划轨迹定义为：

$$x = \begin{cases} S(1 - \frac{2t}{T}) & 0 \leq t \leq \frac{T}{2} \\ S\sin(\frac{\pi(2t-T)}{T}) & \frac{T}{2} < t \leq T \end{cases} \quad (5.20)$$

其中，S和H分别表示四足机器人行走过程中的步长和步高，t是步态轨迹的采样时间，T为摆动腿摆动时间。

#### 4. 三次贝塞尔曲线规划法

贝塞尔曲线是一种典型的差值曲线，具有曲线平滑、计算量小的特点。典型三次贝塞尔曲线的方程为：

$$P(t) = (1-t)^3 P_0 + 3t(1-t)^2 P_1 + 3t^2(1-t) P_2 + t^3 P_3 \quad (5.21)$$

其中，$P_0$ 为足端轨迹起始点，$P_3$ 为终止点，$P_1$ 和 $P_2$ 分别决定起始点处和终止点处的运动方向。

在基于贝塞尔曲线的四足机器人适应性步态规划中，首先利用两条贝塞尔曲线生成封闭的机器人步态周期运动轨迹，其中H表示步高，S表示步长。利用 $P_1$ 和 $P_2$ 相对于 $P_0$ 和 $P_3$ 的位置进行机器人足端离地和入地角度的调整，防止机器人运动过程中出现滑动；利用定义的滤波参数（崎岖度调整参数）对步态周期曲线进行截断处理，实现从摆动阶段到支撑阶段的过渡，以适应高低不平的地形环境。

# 第6章 四足机器人地形识别与路径规划算法

## 6.1 地图创建与地形识别

机器人路径规划就是在已有的全局或局部环境描述中，在多种约束条件下，根据机器人的任务需要，优化出一条从起始点到终止点的可行路径，使该路径与环境中的障碍物无碰撞，并实现规划路径长度短、机器人行进能耗低、算法计算速度快等优化目标。

在机器人路径规划中，首先要已知自身所处的环境，对周围的地图和地形进行识别。

### 常用地图类型

#### 1. 拓扑地图

拓扑地图在机器人领域中应用较早，其在创建过程中无须精确的距离度量信息，构建简单。然而当环境中存在两个具有相似拓扑结构的区域时，拓扑地图很难对其进行区分，因此其应用存在一定的局限性。

#### 2. 几何地图

几何地图又称基于特征的地图，它使用全局坐标表示环境中的一些基本几何图元。由于能提供路径规划、机器人定位所需要的度量信息且存储量相对较小，因此其在基于视觉的同步定位与地图创建研究中应用较多。

#### 3. 栅格地图

栅格地图是对传统几何地图的离散化表示，它将空间表示成连续的区域，每个栅格代表了固定区域的大小且可以用于记录不同的信息，但其缺点为占用的数据量相对较大，对于大场景下的机器人自主导航任务，较难适应。

#### 4. 三维环境地图

随着四足机器人技术的研究逐步由结构化环境转向非结构化环境，上述平面地图已经较难适用于复杂环境下机器人环境感知的要求。三维环境地图由于记录了更加丰富的环境信息，现在成了机器人领域更为常用的环境表示方式。

三维地图表示方法包括：
- (a) 原始数据
- (b) 三维栅格地图
- (c) 高程地图
- (d) 多层地图

## 6.2 全局路径规划算法

全局路径规划是指在机器人所处环境全部已知的情况下，对环境建立地图描述，并通过多种搜索算法在建立的环境地图描述中搜索无碰撞优化路径。

### 常用算法分类

**基于图的搜索算法**：Dijkstra算法、A*算法、D*算法等。

**基于采样的路径规划算法**：概率路标法(Probabilistic RoadMap，PRM)和快速扩展随机树算法(Rapidly exploring Random Tree，RRT)。

### 6.2.1 栅格法

栅格法在地图建模中应用十分广泛。通过将地图划分为均匀网格，将地图空间栅格化，通过每个栅格内的数据信息记录地图特征。

- **二值化栅格地图**：将障碍物所在栅格标记为1，将非障碍物所在栅格标记为0。
- **复杂栅格地图**：除标记该栅格是否可通过之外，还记录着机器人穿越可通行栅格花费的代价。

**栅格分辨率选择**：栅格过大，会导致地图建模不够精确；栅格过小，会增加路径规划的计算量。

#### 障碍物表示假设

1. 二维栅格地图中的障碍物面积即障碍物实体相对地面的最大投影面积，障碍物的高度信息不参与计算。
2. 环境中障碍物的位置和大小信息通过各种传感器采集得到，经过计算机处理，转化为二值信息栅格。

#### 栅格划分流程

**步骤1**：选定环境空间中的障碍物。
**步骤2**：用多个矩形包络障碍物，可得出边长的最大、最小值。
**步骤3**：分别求解每个矩形的面积：

$$A_i = L_i \times W_i \quad (6.1)$$

**步骤4**：求解n个矩形的区域面积：

$$A_{total} = \sum_{i=1}^{n} A_i \quad (6.2)$$

**步骤5**：第i个栅格的长度：

$$L_{cell} = \frac{A_{total}}{N} \quad (6.3)$$

**栅格单元的长度**：

$$L_{cell} = \sqrt{\frac{A_{total}}{N}} \quad (6.4)$$

**栅格的总数**：

$$N = \frac{L_{map} \times W_{map}}{L_{cell}^2} \quad (6.5)$$

其中，$L_{map}$ 表示地图的长度；$W_{map}$ 表示地图的宽度；$A_{map}$ 表示地图的总面积；$R$ 为单元栅格行数；$C$ 为单元栅格列数。一般情况下，$N$ 的取值范围为100～900；在高密度栅格模型情况下，可以取数万个栅格。

#### 栅格标识方法

**直角坐标系法**：在二维栅格环境模型上创建直角坐标系，以该二维栅格环境模型的左上角为坐标原点。

$$M = \begin{cases} 0 & \text{自由栅格} \\ 1 & \text{障碍栅格} \end{cases} \quad (6.6)$$

**序号法**：为每个单元栅格赋序列值，以此来使所有单元栅格序列化。

$$row = \lfloor \frac{N-1}{C} \rfloor \quad (6.7)$$

$$col = (N-1) \mod C \quad (6.8)$$

### 6.2.2 可视图法

可视图法将障碍物转化为地图中的不规则多边形，并将机器人起始点、终止点及各个多边形之间的可见顶点对两两连接，构成可视图。

**可见性判断规则**：
1. 同一障碍物中，相邻顶点可见，不相邻顶点不可见。
2. 不同障碍物之间顶点可见性的判断则转化为判断顶点连线是否会与其他顶点连线相交的几何问题。

### 6.2.3 A*算法

A*算法是建立在Dijkstra算法基础上的一种启发式搜索算法，它可以规划从起始点到目标点的最优路径。

**评估函数**：

$$f(n) = g(n) + h(n) \quad (6.9)$$

其中，$g(n)$ 表示所搜索到的栅格点的代价值（从起始点到栅格点的路径长度），$h(n)$ 为栅格点到目标点的路径长度（通常采用Manhattan函数进行计算），目标点的f值即最优路径的长度。

**算法流程**：
1. 设置Open列表和Close列表
2. 将起始点存入Open列表
3. 依次取出Open列表中f值最小的元素
4. 更新该元素所有可达节点的估计值
5. 直到取到目标点为止

### 6.2.4 快速扩展随机树算法(RRT)

在快速扩展随机树算法中，当随机树的某个节点扩展至目标点邻域范围内时，则将目标点作为树的一个节点加入该随机树，并形成一条从起始点到目标点之间的由树节点组成的可行无碰撞路径。

**特点**：
- 通过碰撞检测进行扩展，无须对空间环境进行建模
- 在环境建模存在困难的高维空间，以及环境中存在复杂障碍物的情况下，能够快速有效地找到可行路径
- 由于状态空间采样的随机性，得到的路径并不是最优的

### 6.2.5 Bi-Directional快速扩展随机树算法

该算法选取起始点和目标点为树的根节点，分别生成两棵随机扩展树，向对方生长。当两棵扩展树节点之间的距离小于连接阈值时，将两树相连并形成一条可行无碰撞路径。

**算法流程**：
1. 创建二值化地图
2. 分别以起始点和目标点为扩展树的根节点
3. 根据随机概率决定采样点
4. 遍历扩展树寻找距离采样点最近的节点
5. 检查生长距离内是否在障碍物区域内
6. 计算与新叶节点的距离是否小于连接距离阈值

### 路径规划方法对比

在480×640的二值化地图中，起始点坐标为(10,10)，目标点坐标为(430,600)。

| 路径规划方法 | 路径长度 | 用时(s) |
|-------------|---------|---------|
| A*算法 | 790.4000 | 0.6684275 |
| 人工势场法 | — | — |
| RRT算法 | 901.7852 | 0.07239985 |
| 双树RRT算法 | 999.2681 | 0.06955933 |

**分析**：
- A*算法用时较长，但获得的路径最短
- 人工势场法在地图左下角位置陷入了合力为零的局部极小值，未能成功进行路径规划
- RRT算法和Bi-Directional RRT算法运行快，但是获得的路径并非最优路径，且每次运行结果都不同
- 在复杂地图情况下，Bi-Directional RRT算法用时接近RRT算法的一半

## 6.3 局部路径规划算法

局部路径规划算法不依赖于全局环境信息，依靠机器人自身携带的传感器对周围环境进行感知，并实时进行路径规划。

### 6.3.1 人工势场法

人工势场法将势能引入状态空间，目标点对机器人形成引力，障碍物对机器人形成斥力。

**引力势场函数**：

$$U_{att}(q) = \frac{1}{2}\xi d^2(q, q_{goal}) \quad (6.10)$$

其中，$\xi$ 为引力势场常量，$d$ 为机器人与目标的距离。

**斥力势场函数**：

$$U_{rep}(q) = \begin{cases} \frac{1}{2}\eta(\frac{1}{\rho(q)} - \frac{1}{\rho_0})^2 & \rho(q) \leq \rho_0 \\ 0 & \rho(q) > \rho_0 \end{cases} \quad (6.11)$$

其中，$\eta$ 为斥力势场常量，$\rho_0$ 为斥力势场的最大影响距离，$\rho(q)$ 为障碍物与机器人之间的直线距离。

**合势场函数**：

$$U(q) = U_{att}(q) + \sum_{i=1}^{n} U_{rep,i}(q) \quad (6.12)$$

**引力函数**：

$$F_{att}(q) = -\nabla U_{att}(q) = \xi(q_{goal} - q) \quad (6.13)$$

**斥力函数**：

$$F_{rep}(q) = -\nabla U_{rep}(q) = \begin{cases} \eta(\frac{1}{\rho(q)} - \frac{1}{\rho_0})\frac{1}{\rho^2(q)}\nabla\rho(q) & \rho(q) \leq \rho_0 \\ 0 & \rho(q) > \rho_0 \end{cases} \quad (6.14)$$

**合力**：

$$F(q) = F_{att}(q) + \sum_{i=1}^{n} F_{rep,i}(q) \quad (6.15)$$

### 6.3.2 神经网络法

#### 1. 路径规划原理

在基于神经网络的路径规划方法中，机器人的运动空间是由神经网络组成的拓扑状态空间，所有神经元的活性值被初始化为0，每个神经元活性值的变化由下式表示：

$$\frac{dx_i}{dt} = -A x_i + (B - x_i)([I_i^+] + \sum_{j=1}^{M} w_{ij} x_j) - (x_i + C)([I_i^-] + \sum_{j=1}^{M} w_{ij} x_j) \quad (6.16)$$

其中，$x_i$ 为第i个神经元的活性值；$A$ 为正常数（衰减率）；$B$ 为神经元活性值的上界；$C$ 为神经元活性值的下界；$I_i^+$ 为第i个神经元的外部输入。

**连接权值函数**：

$$w_{ij} = f(|x_i - x_j|) = \begin{cases} \mu & |x_i - x_j| \leq r_d \\ 0 & |x_i - x_j| > r_d \end{cases} \quad (6.17)$$

#### 2. 环境映射方法

采用神经网络的路径规划算法需要先将环境地图映射入神经网络，并设置神经元的值来表征不同的地图状况。

**寻路搜索方向**（8个方向）：
```
8 1 2
7 R 3
6 5 4
```

#### 3. 基于递归神经网络的实时路径规划方法

第i个神经元离散时间动态方程为：

$$x_i(t+1) = (1-\epsilon)x_i(t) + \epsilon\{[I_i^+ + \sum_{j=1}^{M} w_{ij} x_j(t)]^+ - [I_i^- + \sum_{j=1}^{M} w_{ij} x_j(t)]^-\} \quad (6.19)$$

**连接权值计算**：

$$w_{ij} = \begin{cases} \mu & \text{if } |p_i - p_j| \leq r_d \\ 0 & \text{otherwise} \end{cases} \quad (6.20)$$

**外部输入**：

$$I_i = \begin{cases} E & \text{if } i = goal \\ -E & \text{if } i \in obstacle \\ 0 & \text{otherwise} \end{cases} \quad (6.22)$$

#### 4. 计算机仿真与分析

**实验设置**：
- 5个障碍物（4个矩形，1个运动的多圆点障碍物）
- 起始点：[0.1, 0.2]
- 终止点：[0.9, 0.9]
- 栅格数：50
- 神经元外部输入：100
- 传感器：8个距离传感器（0°到360°均匀安装）

**仿真结果**：
- 无障碍物时，机器人可以选择最短路径
- 有固定障碍物时，可以较好地实现避障运动
- 有动态障碍物时，也能实现较好的路径规划和避障

# 第7章 四足机器人运动控制方法

## 7.1 控制预备知识介绍

### 自动控制基本概念

自动控制是指在没有人直接参与的情况下，利用外加的设备或装置，通过自动地采集运动信息，使系统的某个工作状态或参数自动地按照预定的规律运行的控制方法。

### 控制系统分类

#### 1. 开环控制系统

在开环控制系统中，系统的输出量对系统的控制作用没有影响。其控制量与被控制量之间只有前向通道而没有反向通道，信息的传递路径不是闭合的。

#### 2. 闭环控制系统

在闭环控制系统中，系统的输出信号对控制作用有直接的影响。控制装置对被控对象所施加的控制作用(控制器输出)若部分或全部取自被控量的反馈信息，则这种控制原理称为反馈控制原理。

### PID控制器

在机器人控制系统中，使用最多的、最典型的控制器是PID控制器。由比例单元P、积分单元I和微分单元D组成。

#### (1) 比例环节

加水量 $u$ 和当前液面与目标液面的高度距离差成正比：

$$u = K_p \cdot e$$

- 增大比例系数一般会加快系统响应
- 单纯采用比例单元有可能会出现稳态误差
- 增大比例系数可以减小稳态误差

#### (2) 比例环节+积分环节

$$u = K_p \cdot e + K_i \int e \, dt$$

- 积分环节可以消除系统稳态误差
- 可能会产生超调
- $K_i$ 值越大，系统振荡越大，调整时间变短；$K_i$ 值越小，系统振荡小，但调整时间较长

#### (3) 微分环节

$$u = K_p \cdot e + K_i \int e \, dt + K_d \frac{de}{dt}$$

- 微分环节可以减少系统控制过程中的振荡
- 防止液面高度超过目标高度

## 7.2 机器人控制方法及仿真分析

### 7.2.1 机器人动力学模型

四足机器人在实际构造中，单腿可以用3自由度机械手表示。

**机器人关节参数**：

| 类型 | 符号 | 值 | 单位 |
|------|------|-----|------|
| 连杆1的长度 | l1 | 0.297 | m |
| 连杆2的长度 | l2 | 0.297 | m |
| 连杆1的质量 | m1 | 0.38 | kg |
| 连杆2的质量 | m2 | 0.34 | kg |
| 连杆1的惯量 | I1 | 0.234×10⁻³ | kg·m² |
| 连杆2的惯量 | I2 | 0.068×10⁻³ | kg·m² |
| 重力加速度矢量 | g | 9.8 | m/s² |

**机械臂末端位置**：

$$x = l_1 c_1 + l_2 c_{12} \quad (7.1)$$

**雅可比矩阵**：

$$J = \begin{bmatrix} -l_1 s_1 - l_2 s_{12} & -l_2 s_{12} \\ l_1 c_1 + l_2 c_{12} & l_2 c_{12} \end{bmatrix} \quad (7.2)$$

**动力学方程**：

$$M(q)\ddot{q} + C(q, \dot{q})\dot{q} + G(q) = \tau \quad (7.3)$$

其中：
- $M(q)$ 为对称正定惯性矩阵
- $C(q, \dot{q})$ 为科氏力和离心力矩阵
- $G(q)$ 为重力矢量
- $\tau$ 为控制力矩矢量
- $q, \dot{q}, \ddot{q}$ 分别为关节位置、速度和加速度矢量

**动力学性质**：

**性质1(有界性)**：存在4个正定常数 $m_0, m_1, M_0, M_1$，对任意的 $t \geq 0$ 使得 $m_0 \leq \|M(q)\| \leq M_0$，$\|C(q, \dot{q})\| \leq M_1 \|\dot{q}\|$。

**性质2(反对称性)**：矩阵 $\dot{M} - 2C$ 是反对称的，即 $\xi^T(\dot{M} - 2C)\xi = 0$。

**性质3(参数线性化)**：对 $q, \dot{q}, \ddot{q}$，式(7.3)关于常数参数向量 $\theta$ 可通过以下参数进行线性化：$M(q)\ddot{q} + C(q, \dot{q})\dot{q} + G(q) = Y(q, \dot{q}, \ddot{q})\theta$，其中 $Y$ 是回归矩阵。

**引理7.1(Lyapunov引理)**：如果标量函数 $V(x,t)$ 存在下界，其导数 $\dot{V} < 0$，且关于时间t是一致连续的，那么 $\lim_{t \to \infty} \dot{V} = 0$。

**引理7.2(Barbalat引理)**：如果可微函数 $f(t)$ 在 $t \to \infty$ 时存在有限极限，且一致连续，那么当 $t \to \infty$ 时，$\dot{f}(t) \to 0$。

**推论7.1**：如果可微函数 $f(t)$ 在 $t \to \infty$ 时存在有限极限，$\dot{f}(t)$ 存在并且有界，那么当 $t \to \infty$ 时 $\dot{f}(t) \to 0$。

### 7.2.2 机器人控制方法和控制器设计

#### 1. PD控制

**基本原理**：控制的目标是在存在时变扰动情况下，通过设计合理的控制算法，使得其能够跟踪期望的运动轨迹。

**追踪误差**：$e = q_d - q$

**力矩控制器**：

$$\tau = K_p e + K_d \dot{e} \quad (7.9)$$

**Lyapunov函数**：

$$V = \frac{1}{2} \dot{e}^T M \dot{e} + \frac{1}{2} e^T K_p e \quad (7.11)$$

**仿真实现**：
- 期望运动轨迹：$q_d = [\sin(t), \sin(t), \sin(t)]^T$ (单位rad)
- 初始位置：$q(0) = [0, 0, 0]^T$ (单位rad)
- 初始速度：$\dot{q}(0) = [0, 0, 0]^T$ (单位rad/s)
- PD控制增益：$K_p = 100I_3$，$K_d = 20I_3$

**仿真结果**：PD控制可以实现各个关节的跟踪控制，速度跟踪曲线存在一定的误差。

#### 2. 自适应控制

**基本原理**：自适应控制是控制系统设计中一种极重要的方法。它的基本思想是估计系统未知参数的值，通过适当设计的反馈控制律驱使系统达到期望的目标。

**参数线性化特性**：

$$M(q)\ddot{q} + C(q, \dot{q})\dot{q} + G(q) = Y(q, \dot{q}, \ddot{q})\theta \quad (7.16)$$

**自适应轨迹跟踪控制律**：

$$\tau = Y(q, \dot{q}, \dot{q}_r, \ddot{q}_r)\hat{\theta} - K_D s \quad (7.17)$$

其中，$s$ 为跟踪滤波误差(滑模向量)：

$$s = \dot{e} + \Lambda e \quad (7.18)$$

**参数估计更新律**：

$$\dot{\hat{\theta}} = -\Gamma^{-1} Y^T s \quad (7.27)$$

**Lyapunov稳定性分析**：

$$V = \frac{1}{2} s^T M s + \frac{1}{2} \tilde{\theta}^T \Gamma^{-1} \tilde{\theta} \quad (7.23)$$

**仿真实现**：机器人各个关节均能追踪到预先给定的期望轨迹和期望速度，说明滑模自适应控制算法是非常有效的。

#### 3. 状态信息完全已知情况下的神经网络控制

**RBF神经网络**：由三层组成，输入层节点的作用是传递信号到隐层；隐层节点由径向基函数构成；输出层节点通常是简单的线性函数。

**神经网络近似**：

$$f(x) = W^T \phi(x) + \epsilon \quad (7.30)$$

其中 $W^*$ 是理想最优权重，$\epsilon$ 是逼近误差。

**控制律设计**：

$$\tau = \hat{W}^T \phi(x) + u_{rob} \quad (7.48)$$

**自适应律**：

$$\dot{\hat{W}} = -\Gamma \phi(x) s^T - \sigma \Gamma \hat{W} \quad (7.50)$$

**仿真实现**：
- RBF神经网络隐层神经元：256个
- 中心取值：1
- 宽度取值：0.02
- 外界扰动：$d(t) = [0.5\sin(2\pi t), 0.5\cos(2\pi t), 0.5\sin(\pi t)]^T$

**结论**：基于RBF神经网络设计的控制率对实现机器人轨迹追踪行为是有效的，三个关节均能准确地追踪到预先给定的期望轨迹与期望速度。

#### 4. 部分状态信息未知情况下的神经网络控制

**高增益观测器**：

$$\dot{\hat{x}} = A\hat{x} + Bu + L(y - \hat{y}) \quad (7.53)$$

**控制律**：

$$\tau = \hat{W}^T \phi(\hat{x}) + K_D s + v_{rob} \quad (7.54)$$

**自适应律**：

$$\dot{\hat{W}} = -\Gamma \phi(\hat{x}) s^T - \sigma \Gamma \hat{W} \quad (7.55)$$

**结论**：具有高增益观测器的输出反馈自适应神经网络控制协议对实现机器人轨迹追踪行为是十分有效的。

#### 5. 滑模控制

**基本思想**：
1. 选择一个滑动集
2. 确定一个滑模控制律，驱使滑动集外的状态进入滑动集
3. 用一个使滑动模上的状态沿着滑模到达期望的平衡点

**滑模控制律**：

$$\tau = M(q)\ddot{q}_r + C(q, \dot{q})\dot{q}_r + G(q) - K_D \text{sgn}(s) \quad (7.63)$$

**滑动面误差**：

$$s = \dot{e} + \Lambda e \quad (7.73)$$

**控制律**：

$$\tau = Y\hat{\theta} - K_D \text{sgn}(s) \quad (7.77)$$

**自适应律**：

$$\dot{\hat{\theta}} = -\Gamma^{-1} Y^T s \quad (7.78)$$

**Lyapunov函数**：

$$V = \frac{1}{2} s^T M s + \frac{1}{2} \tilde{\theta}^T \Gamma^{-1} \tilde{\theta} \quad (7.79)$$

**输出约束控制**：采用障碍李雅普诺夫函数，确保所有信号有界且不违反输出约束。

#### 6. 阻抗控制

**阻抗控制原理**：将机器人的力/位置控制系统等效为一个弹簧质量阻尼系统。

**目标阻抗模型**：

$$M_d \ddot{x} + B_d \dot{x} + K_d x = F_e \quad (7.93)$$

其中：
- $M_d$ 为等效目标阻抗模型的惯性矩阵
- $B_d$ 为阻尼矩阵
- $K_d$ 为刚度矩阵

**笛卡尔空间动力学**：

$$M_x \ddot{x} + C_x \dot{x} + G_x = F + F_e \quad (7.101)$$

**神经网络近似**：

$$M_x(x) = W_M^T \phi_M(x) + \epsilon_M \quad (7.105)$$
$$C_x(x, \dot{x}) = W_C^T \phi_C(x, \dot{x}) + \epsilon_C \quad (7.106)$$
$$G_x(x) = W_G^T \phi_G(x) + \epsilon_G \quad (7.107)$$

**控制律**：

$$\tau = J^T(\hat{M}_x u + \hat{C}_x \dot{x} + \hat{G}_x - F_e) \quad (7.117)$$

**自适应律**：

$$\dot{\hat{W}}_M = -\Gamma_M \phi_M(x) e_M^T s^T - \sigma_M \Gamma_M \hat{W}_M \quad (7.129)$$
$$\dot{\hat{W}}_C = -\Gamma_C \phi_C(x, \dot{x}) e_C^T s^T - \sigma_C \Gamma_C \hat{W}_C \quad (7.130)$$
$$\dot{\hat{W}}_G = -\Gamma_G \phi_G(x) e_G^T s^T - \sigma_G \Gamma_G \hat{W}_G \quad (7.131)$$

**仿真结果**：基于阻抗控制神经网络算法实现三自由度机器人轨迹跟踪控制是有效的，机器人所有的关节都能准确跟踪预先设定的期望轨迹。

# 第8章 四足机器人稳定性判定方法

## 8.1 四足机器人步态选择策略

在四足机器人的运动控制中，需要考虑机器人运动过程中的稳定性。当机器人在静态行走和奔跑时，为了防止身体失稳，出现跌倒或者倾覆，甚至机器人损坏，必须考虑机器人的稳定性控制问题。

### 弗劳德(Froude)数

为了比较不同生物的步态，可以用弗劳德数来定义：

$$Fr = \frac{u^2}{gh} \quad (8.1)$$

其中，$u$ 表示动物的运动速度，$g$ 表示重力加速度，$h$ 表示身体躯干中心与地面的距离。

**步态转换临界值**：
- 当弗劳德数为0.5左右时，运动步态一般从静步态转换成动步态
- 当弗劳德数为2.5左右时，运动步态从动步态转换成飞奔步态

**示例**：
- 狗从动步态转换成飞奔步态的速度为3.5m/s
- 骆驼的转换速度为2.4m/s
- 两者的弗劳德数相同，均为2.5

### 负重与步态关系

多种不同四足动物的负重与步态速度、步态频率、能量消耗的关系：

| 等价速度 | 步态速度与负重关系 | | 步态频率与负重关系 | | 能量消耗与负重关系 | |
|---------|------------------|---|------------------|---|------------------|---|
| | 系数a | 系数b | 系数a | 系数b | 系数a | 系数b |
| 最优小跑速度 | 1.09 | 0.222 | 3.35 | -0.130 | 5.35 | -0.046 |
| 小跑-奔跑步态 | 1.54 | 0.216 | 4.19 | -0.150 | 5.39 | -0.011 |
| 最优奔跑步态 | 2.78 | 0.176 | 4.44 | -0.156 | 7.21 | 0.04 |

**关系公式**：

$$\text{步态速度(步态频率、能量消耗)} = a \cdot W^b \quad (8.2)$$

其中，$a$、$b$ 为待定常数，$W$ 为四足动物负重，单位为kg。

## 8.2 四足机器人稳定性基本概念

### 8.2.1 稳定裕度

稳定裕度定义为质心的垂直投影与水平面上的支撑模式边界的最小距离。

水平稳定裕度被定义为质心的垂直投影与支撑模式边界在平行于身体运动方向的最小距离。

### 8.2.2 占空比

$$\beta = \frac{t_{support}}{T} \quad (8.3)$$

- 当占空比 ≥ 0.5时，一般认为机器人的步态为静步态
- 当占空比 < 0.5时，步态为动步态

### 8.2.3 阻力系数

$$COT = \frac{E}{Mgd} \quad (8.4)$$

其中，$E$ 是行走距离 $d$ 的总耗能；$M$ 是机器人的总质量；$g$ 是重力加速度。

## 8.3 静态稳定性判定方法

### 1. 静态稳定边界（SSM）法

在给定的支撑区域内，机器人重心投影至支撑区域各边界距离的最小值。

### 2. 纵向稳定边界（LSM）法

在给定的支撑区域内，机器人机体重心的垂直投影至支撑区域前、后边界的较小纵向距离。与SSM方法比较，LSM方法计算较为简单。

### 3. 偏转纵向稳定边界（CLSM）法

沿着机器人运动方向，机器人重心投影到支撑多边形前后边缘的最小距离。当考虑机器人加速过程中的惯性力影响时，该方法比较有效。

### 4. 能量稳定裕度法（ESM）

该方法是指当前机器人在其支撑多边形各边倾倒过程中的所需的最小势能：

$$ESM_i = mgh_i \quad (8.5)$$

其中，$h_i$ 表示机器人躯干质量中心（重心）的高度变化：

$$h_i = |r_i| \sin(\alpha_i - \beta_i) \quad (8.6)$$

其中，$|r_i|$ 表示身体质量中心到旋转角度的距离，$\alpha_i$ 表示 $r_i$ 和垂直轴之间的角度，$\beta_i$ 表示旋转轴相对于水平面的倾角。

### 5. 标准能量稳定裕度（NESM）

$$NESM = \frac{ESM}{mg} \quad (8.7)$$

## 8.4 动态稳定性判定方法

### 1. 零点力矩法（ZMP）

当机器人处于运动状态时，其平衡的必要条件为机器人重力与所受惯性力的合力延长线位于机器人支撑区域内。

**ZMP定义**：

$$x_{ZMP} = \frac{\sum_{i=1}^{n} m_i(\ddot{z}_i + g)x_i - \sum_{i=1}^{n} m_i(\ddot{x}_i)z_i}{\sum_{i=1}^{n} m_i(\ddot{z}_i + g)} \quad (8.8)$$

$$y_{ZMP} = \frac{\sum_{i=1}^{n} m_i(\ddot{z}_i + g)y_i - \sum_{i=1}^{n} m_i(\ddot{y}_i)z_i}{\sum_{i=1}^{n} m_i(\ddot{z}_i + g)} \quad (8.9)$$

**简化形式**（身体质量中心保持恒定高度时）：

$$x_{ZMP} = x_c - \frac{z_c \ddot{x}_c}{\ddot{z}_c + g} \quad (8.10)$$

**动态系统方程**：

$$\ddot{x}_{ZMP} = \frac{g}{z_c}(x_{ZMP} - x_c) + \ddot{x}_c \quad (8.11)$$

### 2. 动态稳定裕度方法（DSM）

基于机器人的动量稳定性准则，需要满足：

$$F_I + F_S + F_G + F_M = 0 \quad (8.13)$$

$$\dot{H}_S = r_S \times F_S = r_S \times (-F_I - F_G - F_M) \quad (8.14)$$

**动态稳定性裕度定义**：

$$DSM = \min_{i=1}^{k} \frac{\dot{H}_i \cdot \hat{n}_i}{\|\dot{H}_i\|} \quad (8.15)$$

其中 $r_i$ 是身体质心到第i个支撑腿的位置向量，$\hat{n}_i$ 是沿着支撑边界顺时针方向的一个单位向量。

### 3. 倾倒稳定性判定法（TSJ）

**合反作用力**：

$$F_R = F_I + F_G + F_M \quad (8.16)$$

**动量**：

$$\dot{H} = \dot{H}_I + \dot{H}_G + \dot{H}_M \quad (8.17)$$

**旋转轴上的动量**：

$$\dot{H}_i = r_i \times F_R + \dot{H} \quad (8.18)$$

**稳定性判定**：

$$\dot{H}_i \cdot \hat{n}_i > 0 \quad (8.19)$$

如果在旋转方向上存在任意支撑腿j使得系统不倾倒，则称系统是动态稳定的。

### 4. 标准动态能量稳定裕度法（NDESM）

机器人重心受6种力和力矩的作用：惯性力 $F_I$ 和惯性力矩 $M_I$，重力 $F_G$ 和重力矩 $M_G$，操纵力 $F_M$ 和操纵力矩 $M_M$。

**合力**：

$$F_R = F_I + F_G + F_M \quad (8.20)$$

$$M_R = M_I + M_G + M_M \quad (8.21)$$

**合力矩**：

$$M_R = M_G + M_{NM} \quad (8.22)$$

**能量改变**：

$$\Delta E = E_2 - E_1 \quad (8.23)$$

**临界状态**：

$$E_c = E_{p2} + E_{k2} = E_{p2} \quad (8.24)$$

**势能增加量**：

$$\Delta E_p = mgh \quad (8.25)$$

**角动量**：

$$L = I\omega = mr^2\omega \quad (8.29)$$

**角速度**：

$$\omega = \frac{L}{I} = \frac{m(r \times v)}{mr^2} \quad (8.30)$$

**动能**：

$$E_k = \frac{1}{2}I\omega^2 \quad (8.31)$$

**稳定性条件**：

$$E_i > 0 \quad \forall i \quad (8.32)$$

**标准动态能量稳定裕度**：

$$NDESM = \frac{\min_{i=1}^{k} E_i}{mg} \quad (8.33)$$

### 5. 改进的泛稳定裕量法（MWSM）

考虑机器人动态步行时惯性力这一重要因素，将机器人重心投影改进为考虑惯性力的动态ZMP点。

**惯性力影响计算**：

$$F_I = ma = m\frac{v^2}{2d} \quad (8.34)$$

$$d = \frac{v^2}{2a} \quad (8.35)$$

**改进策略**：
1. 在匀加速开始的第一周期内，使四足摆动较给定标准步长短d
2. 恢复给定标准步长，使改进的支撑多边形始终位于改进前支撑多边形后方d处
3. 当匀加速运动结束时，在一个周期内使足端向前摆动步长较标准步长增加d

### 6. 着陆符合率法（LAR）

在对角小跑步态中，定义对角小跑步态稳定的判定依据：

$$LAR = \frac{t - t_{nc}}{t} \quad (8.36)$$

其中，$t$ 表示对角腿的支撑时间，$t_{nc}$ 表示对角线上前后两条腿触地时的不协调时间。

**稳定性条件**：$LAR \geq 0.8$ 时表示此时四足机器人保持动态稳定性。

**局限性**：
- 这种动态稳定性的判定标准能够保证在对角小跑步态下，对角腿的协调一致
- 但是并不能完全保证四足机器人的真正稳定性
- 当四足机器人的身体受到较大的惯性力时，很容易倾覆
- 该判定标准仅是对角小跑步态下的一种判定方法，缺乏一般性
