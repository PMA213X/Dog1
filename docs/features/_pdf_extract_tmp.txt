 三、     调节颜色阈值

色而言，这是不利的。于是需要利用图像的二值化凸显出某种颜色。
     下面的链接简单介绍了二值化。

个滑块对应着 RGB 的高阈值。先把左侧三个滑块调至最左侧，右侧三个滑块调

可能遇到的问题
1. ping 不到机器狗
答：检查是否和机器狗连接到同一局域网，检查电脑端是否关掉 wifi，检查网
线连接是否与机器狗保持连接
2. 缺少 libopencv 等相关依赖
答：参考 https://blog.csdn.net/BIT_HXZ/article/details/124887369
错 误 ： error while loading shared libraries: libopencv_core.so.5.0: cannot open
shared object file: No such file or directory
解决：
locate libopencv_core.so.5.0
如：/home/user/trackapp/lib/libopencv_core.so.5.0
若      执     行      该     指       令      没    反    应  ，     路       径    就      是
/home/user/track1.1/build/lib/libopencv_core.so.5.0
sudo cp /home/user/track1.1/build/lib/libopencv_core.so.5.0 /usr/lib/x86_64-linux-
gnu
若仍找不到文件，就切换到 track1.10/build/lib 文件夹下执行该指令。截图是以
track 1.8 为例：


缺少其他依赖以此类推。
3. 机器狗内部缺少 qt
答：用 scp 把虚拟机内对应版本的 qt 发送到机器狗内（发送时注意对应主机和
工控机地址的位置）
4. 机器狗连着网线可以循迹，但是拔掉网线不可以循迹。
答：在 track 之前，先执行以下两个命令。
sudo ifconfig lo multicast
sudo route add -net 224.0.0.0 netmask 240.0.0.0 dev lo
nohup ./track &
5. 错 误 ： ./track: /usr/lib/x86_64-linux-gnu/libQt5Network.so.5: version `Qt_5' not
found (required by ./track)
./track: /usr/lib/x86_64-linux-gnu/libQt5Core.so.5: version `Qt_5.10' not found
(required by ./track)
./track: /usr/lib/x86_64-linux-gnu/libQt5Core.so.5: version `Qt_5' not found (required
by ./track)
原因：qt 版本问题
解决：
在虚拟机根目录下会有 Qt 的包
通过 scp 指令传输到机器狗的 upboard，首先要保证两者网线连接
打开一个终端输入 sudo scp -r Qt/ user@10.0.0.34:/home/user
等待传输完成后
在机器狗的 upboard 根目录下打开一个终端
输                                       入                                       export
LD_LIBRARY_PATH=/home/user/Qt/5.10.0/gcc_64/lib:$LD_LIBARY_PATH
输入 source ~/.bashrc
6. 拔掉网线后循迹程序死掉问题
解决方法：使用指令：nohup sudo ./track & 来运行循迹程序
7.摄像头打开失败
重新启动程序；检查线路，重新插拔；确保调试时间，避免摄像头过热导致打
开失败。
